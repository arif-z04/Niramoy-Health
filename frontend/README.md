# Niramoy Health - Frontend Application (Phase 3)

This directory is designated for the modern, responsive frontend application for Niramoy Health.

## Scope (Phase 3)
- Modern responsive web interface inspired by Arogga, featuring an original brand identity, typography, and palette.
- Product catalog browsing with bilingual search (English & Bengali).
- Prescription upload and verification progress tracker.
- Bangladeshi checkout with Division/District selector and bKash/Nagad/COD payment flows.
- Integration with the ASP.NET Core Web API (built in Phase 2).
